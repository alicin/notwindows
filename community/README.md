# Community setups

Game setups shared by notwindows players. Smart Setup lists the ones for the game you're setting up, and applies one
with a click.

Each game has a folder in `setups/`: the Steam app ID and the game's name for Steam games (`22380-fallout-new-vegas`),
or the executable's name otherwise (`moviesse.exe`). Inside are `.notwindows` files, the same files as **Export
Settings** writes. They carry a game's settings, launch arguments, engine, Winetricks components and .ini changes, the
Mac model, chip and macOS version they ran on, and an optional note; no paths or play history.

## Sharing a setup

Once a game runs well, choose **Share with the Community…** in its tools menu or in the Advanced tab. GitHub opens
with the file filled in at the right place; proposing it opens a pull request. Setups that have had a long session
(notwindows marks them *known good*) help others most.
